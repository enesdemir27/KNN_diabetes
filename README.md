# KNN Diabetes Prediction

Bu proje, K-En Yakın Komşu (KNN) algoritması kullanılarak diyabet hastalığının tahmin edilmesini amaçlamaktadır.

## Proje Hakkında

Bu projede, Pima Yerlileri Diyabet veri seti kullanılarak diyabet hastalığının tahmini için bir makine öğrenmesi modeli geliştirilmiştir. Model, K-En Yakın Komşu algoritması kullanılarak oluşturulmuştur.

## Veri Seti

Projede kullanılan veri seti (`diabetes.csv`), aşağıdaki özellikleri içermektedir:
- Hamilelik sayısı
- Glikoz
- Kan Basıncı
- Deri Kalınlığı
- İnsülin
- BMI (Vücut Kitle İndeksi)
- Diyabet Soyağacı Fonksiyonu
- Yaş
- Sonuç (0 veya 1)

## Gereksinimler

- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
